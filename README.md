# Primera web · Electricidad Cabanes

**🌐 Ver la web: https://alexcabaness.github.io/primera-web-electricidad-cabanes/**

Web de una sola página (HTML/CSS/JS sin dependencias ni servicios de terceros: las fuentes están en `fonts/`) de Electricidad Cabanes, electricista en Monóvar (Alicante).

## Ejecutar en local
Desde esta carpeta:

    python3 -m http.server 8000

y abre http://localhost:8000 (o `npx serve .`).

## Estructura
- `index.html`: todo el CSS y JS está dentro.
- `aviso-legal.html`, `privacidad.html`, `cookies.html` + `legal.css`: textos legales genéricos (pendientes de revisión profesional y de completar titular y NIF).
- `img/`: fotos de trabajos y logos (`logo-cabanes.webp`, `logo-fych.webp`).
- `fonts/`: tipografías alojadas en local.
